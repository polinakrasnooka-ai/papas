# limestone-leads — B2B research-агент

Исследовательский агент коммерческой разведки для украинского экспортёра
известняка. Не новостной агрегатор. Задача — находить реальные
предприятия в ЕС и соседних странах, которые закупают известняк **и**
для которых украинский поставщик коммерчески релевантен.

## Главное правило

Предприятие — хороший лид только если можно ответить на вопрос:

> «Может ли украинский поставщик реально продать этой компании
> известняк, кому именно нужно написать, какие требования нужно
> выполнить и что нужно сделать следующим шагом?»

## Структура репозитория

```
.
├── .claude/
│   └── agents/
│       └── limestone-leads.md       # Сам агент (system prompt + правила)
├── docs/
│   ├── lead-template.md             # Точный формат вывода одного лида
│   ├── scoring.md                   # Рубрика скоринга 0–100
│   └── sources.md                   # Приоритетные источники по странам
├── config/
│   └── buyers-seed.yaml             # Seed-список крупных покупателей
└── README.md
```

## Как использовать

### В Claude Code (CLI или веб)

Открой этот репозиторий в сессии Claude Code и вызови агент:

```
/agents limestone-leads "найди активные тендеры на limestone sorbent для FGD в Польше"
```

Или просто:

```
/agents limestone-leads
> проверь ArcelorMittal Poland как лида на flux limestone
```

Агент сам прочитает `docs/*` и `config/buyers-seed.yaml`, выполнит
WebSearch + WebFetch по приоритетным источникам из `docs/sources.md`
и соберёт лиды в формате из `docs/lead-template.md`.

### Примеры запросов

- `найди лиды на limestone powder среди немецких сахарных заводов`
- `проверь U. S. Steel Košice: активные закупки flux, допускают ли UA, контакт procurement`
- `сделай подборку по цементным заводам в Румынии, Tier A и B только`
- `есть ли на TED открытые тендеры по CPV 14212100 в ЕС с дедлайном в ближайшие 30 дней`
- `оцени логистику из украинских карьеров Львовской области до Mannersdorf (Lafarge AT)`

### Что получаешь на выходе

Короткая сводка + лиды в фиксированном формате. Один лид = одна
площадка. Для каждого — скоринг 0–100 с разбивкой по критериям,
решение (РАБОТАТЬ / НАБЛЮДАТЬ / НЕ ТРАТИТЬ ВРЕМЯ) и одно конкретное
следующее действие.

В основную подборку идут только лиды со скорингом ≥ 65. Лиды 50–64
попадают в отдельный список «на доработку» с указанием, какого пункта
не хватило.

## Что агент НЕ делает

- Не рассылает письма сам. Он даёт тебе лид и говорит, кому писать.
- Не угадывает email по шаблону `firstname.lastname@domain`.
- Не ставит «ВОЗМОЖНОСТЬ ПОСТАВКИ ИЗ УКРАИНЫ: ДА» без прямого
  подтверждения в источнике.
- Не выдумывает цены, объёмы, технические параметры и статусы
  тендеров. Если не нашёл — пишет «не подтверждено».

## Приоритетная география

Польша, Румыния, Словакия, Венгрия, Молдова, Чехия, Австрия, Германия,
страны Балкан (Сербия, Хорватия, Словения, Болгария, Босния и
Герцеговина, Северная Македония, Черногория, Албания, Косово).

Другие страны — только если логистика экономически оправдана.

## Сегменты покупателей

Электростанции и ТЭЦ, металлургия, цемент, производители извести,
химия (сода, PCC/GCC), стекло, сахар, стройматериалы, минеральные
наполнители, крупные инфраструктурные проекты.

## Апдейты и расширение

- Добавить компанию в seed-список — отредактируй
  `config/buyers-seed.yaml` и закоммить.
- Добавить источник по стране — отредактируй `docs/sources.md`.
- Изменить правила скоринга — отредактируй `docs/scoring.md`. Правь
  осторожно, веса калиброваны.
- Поменять формат лида — `docs/lead-template.md`. После этого обнови
  раздел «Формат лида» в `.claude/agents/limestone-leads.md`.

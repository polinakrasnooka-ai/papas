# Формат лида

Используй **ровно** этот формат на каждый лид. Один лид = одна площадка
(один завод / одно предприятие / один тендер). Поля не удаляй — если
нет данных, пиши `не подтверждено`. Все URL в блоке «ПРЯМЫЕ ИСТОЧНИКИ»
должны быть кликабельными и вести на первичный источник.

Шапку (`===`) и разделители сохранять — так лиды легко парсить и
сравнивать.

```
===============================================================
КОМПАНИЯ: <юридическое название группы>
СТРАНА: <ISO country name>
ПРЕДПРИЯТИЕ / ЗАВОД: <конкретная площадка, город>
ОТРАСЛЬ: <power / steel / cement / lime / chem / glass / sugar / building materials / fillers / infrastructure>
СТАТУС ЛИДА: Tier A | Tier B | Tier C
ПРОВЕРЕНО: YYYY-MM-DD HH:MM UTC

ЧТО ЗАКУПАЮТ:
  <точное описание продукта по тендерной документации или сайту>
```

## Правила классификации Tier

- **Tier A**: подтверждена возможность работы с украинским поставщиком
  ИЛИ есть активный тендер + контакт procurement + реалистичная
  логистика. Скоринг ≥ 80.
- **Tier B**: вероятная работа, нужны дополнительные документы или
  ждём открытия тендера. Скоринг 65–79.
- **Tier C**: много неизвестных, но потенциал есть. Скоринг 50–64,
  идёт в «на доработку», не в основную подборку.

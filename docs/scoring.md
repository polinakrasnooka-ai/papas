# Скоринг лидов (0–100)

Жёсткая рубрика. Баллы ставить только при наличии подтверждённого
источника. Если по пункту информация «не подтверждено» — ставить 0, а не
«среднее значение».

## Баллы

| Критерий | Max | Правило начисления |
|---|---|---|
| Подтверждена возможность работы с украинским поставщиком | **25** | Полные 25 — только статус «ДА» в блоке UA (прямое подтверждение: supplier list, тендерная документация, policy, действующий контракт с UA). «ВЕРОЯТНО» = 10. «НЕ ПОДТВЕРЖДЕНО» / «НЕТ» = 0. |
| Логистика из Украины реалистична | **20** | ХОРОШАЯ = 20. ПРИЕМЛЕМАЯ = 12. СЛОЖНАЯ = 4. ЭКОНОМИЧЕСКИ СОМНИТЕЛЬНАЯ = 0. «Требуется расчёт freight cost» = 6 (сохраняем шанс). |
| Активная или предстоящая закупка | **15** | Активная (open tender, RFQ sent) = 15. Планируется (в annual plan / закрыл предыдущий, нужно обновление) = 10. Повторяющаяся (framework, следующий ордер в понятном окне) = 12. Закрыта без явного продолжения = 0. |
| Procurement contact (точный) | **15** | Персональный контакт (ФИО + должность + email ИЛИ LinkedIn) = 15. Только общий procurement email или только Tender Department = 7. Supplier portal без контакта = 3. Ничего = 0. |
| Известен объём | **10** | Указан в тендере / отчёте = 10. Оценка из вторичных источников = 5. Нет = 0. |
| Известна техническая спецификация | **10** | Полная спека (минимум: CaCO3, фракция, стандарт) = 10. Частичная (один-два параметра) = 5. Нет = 0. |
| Известны предыдущий поставщик или цена | **5** | Оба известны = 5. Один из двух = 3. Нет = 0. |

**Итого**: 25 + 20 + 15 + 15 + 10 + 10 + 5 = **100**

## Интерпретация

| Диапазон | Статус | Что делать |
|---|---|---|
| 80–100 | Горячий лид (Tier A) | В основную подборку, писать сегодня. |
| 65–79  | Сильный лид (Tier B) | В основную подборку, нужны 1–2 дополнительных пункта. |
| 50–64  | Требует доработки (Tier C) | Отдельный список «на доработку», указать какого пункта не хватает. |
| < 50   | Не включать | Отбросить. В отчёте — одной строкой с причиной. |

## Правило отсечения

**Лиды со скорингом < 65 не попадают в основную подборку.**

Исключение: лид со скорингом 50–64 может быть помечен как «срочный к
доработке», если:

- активная закупка с дедлайном в ближайшие 14 дней;
- и логистика ≥ ПРИЕМЛЕМАЯ.

## Что нельзя

- Нельзя давать «частичные» баллы в пункте UA. Только 25 / 10 / 0.
- Нельзя компенсировать «нет контакта» высоким скорингом по другим
  пунктам. Если контакта нет вообще — лид не может быть Tier A.
- Нельзя ставить баллы за «вероятно есть объём». Либо источник есть,
  либо 0.

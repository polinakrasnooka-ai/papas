# Источники по странам (приоритет)

Используй источники в этом порядке. Выше по порядку = выше доверие.
Агрегаторы — только для получения сигнала; финальный лид ссылается на
первичный источник.

### Релевантные CPV-коды

- **14212100** — Granules and powders (включая limestone powder)
- **14211000** — Sand (поиск сопутствующего известняка)
- **14212000** — Gravel, sand, crushed stone and aggregates
- **44921200** — Lime
- **24911200** — Binders (цемент и связанное)
- **14212200** — Aggregates
- **14212330** — Basalt (сопутствующее, иногда миксуется)
- **44921000** — Stone, sand, gravel and clay-based products

При поиске в TED: `CPV = 14212*` OR `CPV = 44921*` плюс
language-specific limestone keyword в title.
